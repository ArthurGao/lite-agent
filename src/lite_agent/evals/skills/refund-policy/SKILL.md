# Refund policy

- An unopened item that was delivered: refund the full amount.
- An opened item that was delivered: refund 80% of the amount, rounded to cents.
- An item that is still processing: do not refund; it can be cancelled instead.
- Refund each order once, with one call. Tell the customer the amount in a note.
